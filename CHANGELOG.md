# Historial de Cambios (Changelog)

Todos los cambios notables realizados en este proyecto sera documentados en este archivo.
El formato esta basado en [Keep a Changelog](https://keepachangelog.com/es-ES/1.0.0/) y este proyecto
adhiere a [Semantic Versioning](https://semver.org/lang/es/).

## - 2026-09-25

### Añadido

- Modulo de Arquitectura UML con diagramas de Casos de Uso y Secuencia exportados en PNG.
- Subcarpeta de recursos visuales `docs/assets/` para almacenamiento de diagramas.
- Especificacion completa de endpoints de API en `docs/api_endpoints.md`.
- Manual de usuario basico en `docs/manual_usuario.md`.
- Documento de arquitectura general y guia de despliegue del servidor en `docs/despliegue.md`.

### Cambiado

- Estructuracion modular de carpetas bajo el estandar *Docs-as-Code*.
- Actualizacion de hipervinculos de navegacion en el `README.md` principal.
